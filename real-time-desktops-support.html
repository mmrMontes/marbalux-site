REAL-TIME DESKTOPS

App support

Setup, monitor selection and troubleshooting for Real-Time Desktops.

Start with the quick guide below and review the common questions for help with setup and everyday use. If you still need assistance, you can find the support contact information through the app's Microsoft Store listing after these resources.

Real-Time Desktops: quick start

  1. Install the app from Microsoft Store and open it from Start.
  2. Follow the welcome tutorial. You can reopen it from the system tray menu.
  3. Press Ctrl + Alt + D, the default shortcut, or use the system tray icon to open the overview.
  4. Click a desktop card to switch. Click its title to rename it; Enter saves and Esc cancels the edit.
  5. Use + in the overview to add a virtual desktop. Select × on a desktop card to remove it; at least one desktop must remain.
  6. Use the monitor selector (▣) in the overview to choose any connected display. The app also works with a single monitor. With multiple monitors, keep the overview visible on a dedicated screen for continuous, real-time viewing while you work on another.
  7. Open Settings from the tray to change language, refresh intervals, shortcut and animations.

Common questions

Which Windows version do I need?

Windows 11, 64-bit (x64), with virtual desktops and desktop composition enabled. Real-Time Desktops does not require its own account.

Do I need more than one monitor?

No. Real-Time Desktops works on a single monitor: open the overview to view, manage and switch between your virtual desktops. With multiple monitors, you can also keep the live overview visible on one screen while you work on another.

Can I keep the live overview on another monitor?

Yes. Use the monitor selector (▣) in the overview to choose any connected monitor. The overview moves to that screen and can stay visible with real-time updates while you work on another. Refresh intervals are configurable in Settings; minimized or protected windows may limit previews.

Why is the shortcut not working?

Another app may be using the same key combination. Open Settings from the tray and choose a different shortcut.

Why are some previews incomplete?

Minimized or protected windows may limit previews. The taskbar strip uses the available capture for each desktop and refreshes when you visit it. It does not continuously reflect changes on unvisited desktops.

How do I close the app?

Esc can stop an animation; press it again to close the overview. The app remains available in the system tray. Select Exit from the tray menu to close it completely.

How do I reopen the tutorial?

Select Tutorial from the tray menu. You can change its language and choose whether it appears at startup.

How do I uninstall Real-Time Desktops?

Close the app with Exit, then open Windows Settings → Apps, find Real-Time Desktops and select Uninstall. Uninstalling the app does not remove Windows virtual desktops or files belonging to other applications.

Purchases and billing

Acquisition is handled by Microsoft Store. Check the listing for pricing and availability in your region. For charges, receipts or refund requests, use your Microsoft order history and Microsoft support.

Still need help?

If the quick guide and common questions do not resolve your issue, consult the support contact information in the Real-Time Desktops listing on Microsoft Store.

When contacting support, include your Windows version, the app version shown in About, and the steps to reproduce the issue. Hide private information in screenshots and do not send passwords or payment details.
